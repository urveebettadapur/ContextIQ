ContextIQ is a beginner-friendly Retrieval-Augmented Generation application.

Retrieval-Augmented Generation, commonly called RAG, combines information retrieval with text generation. Instead of relying only on information stored inside a language model, a RAG system retrieves relevant information from an external knowledge source and provides that information to the model as context.

A typical RAG pipeline consists of several stages. Documents are first loaded into the system and divided into smaller chunks. Each chunk is converted into an embedding, which is a numerical representation of its semantic meaning. The embeddings are stored in a vector database.

When a user asks a question, the question is converted into an embedding. The system performs a similarity search against the stored document embeddings and retrieves the most relevant chunks. These chunks are then provided to the language model along with the user's question.

The language model uses the retrieved context to generate an answer. RAG can help reduce hallucinations because the model has access to relevant external information when generating its response.

Embeddings allow systems to compare pieces of text based on semantic meaning rather than relying only on exact keyword matches. Texts with similar meanings tend to have embeddings that are close together in vector space.

Chroma is a vector database that can store embeddings and perform similarity searches. ContextIQ uses Chroma as its local vector store.

Ollama allows large language models to run locally on a computer. ContextIQ uses the Llama 2 model through Ollama for generating answers.

LangChain is a framework that provides components for building applications powered by language models. ContextIQ uses LangChain to connect document processing, embeddings, vector retrieval, and the language model.

Python is the primary programming language used to develop ContextIQ.

The main advantage of RAG is that a knowledge base can be updated without retraining the underlying language model. This makes RAG useful for applications such as document question answering, internal knowledge assistants, customer support systems, and research tools.

ContextIQ is designed as a learning project to demonstrate the fundamental RAG pipeline: retrieval, context augmentation, and generation.

The project does not use a cloud-hosted LLM. Llama 2 runs locally through Ollama, allowing the application to work without an external LLM API key.

The system retrieves the two most relevant chunks from the knowledge base for each user question. The retrieved chunks are included in the prompt sent to the language model.

ContextIQ instructs the language model to answer only using the retrieved context. If the required information is not available in the provided context, the model should state that it does not know the answer based on the available knowledge.
